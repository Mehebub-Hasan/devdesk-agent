# DevDesk Agent

DevDesk Agent is an AI workspace assistant that helps developers and students understand their local projects, documents, code files, and notes using retrieval-augmented generation (RAG).

The goal of this project is to build a practical AI developer tool that can:

- Read project files
- Understand documents and code
- Search relevant context
- Answer questions from uploaded files
- Generate useful developer tasks

# Core Features

## MVP Features

- Upload project files
- Extract text from files
- Split text into chunks
- Generate embeddings
- Store vectors using FAISS
- Ask questions about uploaded content
- Return answers with source references
